# Gayane — Dance World 3D

3D-игра для изучения испанского (A2 → B2) с переводами на армянский. React + TypeScript + Vite + Three.js.
Персонажи, анимации, локации и музыка созданы кодом; сторонних моделей, записей и картинок нет.

## Запуск
    npm install
    npm run dev      # разработка
    npm run build    # проверка типов + сборка в dist/
    npm run preview  # просмотр сборки
    npm run check    # проверка контента: переводы, ответы, алфавит

Нужен Node 20+. Сервер обязателен: файл dist/index.html двойным щелчком не откроется.

## Публикация
- **Netlify**: перетащите папку `dist` на app.netlify.com/drop или подключите репозиторий.
- **Vercel**: импортируйте репозиторий, пресет Vite, папка `dist`.
- **GitHub**: загрузите содержимое архива в репозиторий (node_modules не нужен).

## Где что лежит
- `src/data` — диалоги, 100 вопросов, грамматика, города, задания игр
- `src/lang` — словарь испанский → армянский, озвучивание
- `src/three` — персонажи, движения, сцены, движок
- `src/ui` — танцы, мини-игры, сюжет, магазин, панели
- `src/audio` — синтезатор музыки

Новая фраза пишется так: `"Hola|Բարև"`. После правок запустите `npm run check`.

## Управление
WASD/стрелки — ходьба, Shift — бег, E — действие, M — карта, Esc — пауза. Танец: стрелки или D F J K.
На телефоне — джойстик и касания. Нажатие на любое испанское слово показывает перевод; на кнопках — значок «ա».

Прогресс хранится в браузере (localStorage). Голос берётся из устройства: для озвучивания нужен испанский голос в системе.
